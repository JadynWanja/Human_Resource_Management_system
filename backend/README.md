# HRMS Flask Backend

This backend provides the required HRMS features for authentication, employee records, departments, leave requests, attendance, dashboard analytics, and notifications.

## Run

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
